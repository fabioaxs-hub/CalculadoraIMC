# Calculadora de IMC (Índice de Massa Corporal)

Uma aplicação web simples, leve e responsiva para calcular o Índice de Massa Corporal (IMC) e classificar o resultado de acordo com os parâmetros da Organização Mundial da Saúde (OMS).

---

## 🚀 Funcionalidades

* **Cálculo em Tempo Real:** Calcula o IMC instantaneamente com base no peso (kg) e na altura (m).
* **Classificação Automática:** Informa a faixa de peso correspondente (Abaixo do peso, Peso normal, Sobrepeso, Obesidade grau I, II ou III).
* **Design Responsivo:** Adaptado para funcionar perfeitamente tanto em computadores quanto em dispositivos móveis.
* **Interface Limpa:** Desenvolvida com foco na experiência do usuário (UX) e facilidade de uso.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais, sem necessidade de frameworks complexos:

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização, layout flexível e responsividade.
* **JavaScript (ES6+):** Lógica de cálculo e manipulação do DOM.
